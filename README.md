# Mi grupo

Una app sencilla para cuidar a cada persona de un grupo de predicación: a quién le toca esta semana, cómo está cada uno y qué hablar con tu auxiliar.

- Se empieza pegando la lista del grupo, una persona por línea.
- No guarda nada en ningún servidor: los datos se quedan en el móvil de quien la usa.
- En el iPhone: ábrela en Safari, toca Compartir → «Añadir a pantalla de inicio» y úsala siempre desde el icono.
